📋 Overview

The home screen displays two main service categories to help users discover services:

🔥 Popular Services

Services ranked by popularity score based on bookings and views.

⭐ Top Rated Services

Services sorted by rating quality and review count.

🔥 Popular Services

Algorithm

Popular services are sorted by popularityScore which considers:

  • Number of bookings
  • View count
  • Recent activity
// Sort by popularity score const popularServices = [...services] .sort((a, b) => b.popularityScore - a.popularityScore) .slice(0, 8);

Implementation

File: app/api/services/home/route.ts

Fetches ACTIVE services from database and applies popularity sorting.

⭐ Top Rated Services

Algorithm

Combines average rating with review count for quality scoring:

// Combined score calculation const scoreA = a.rating + (a.reviews / 100); const scoreB = b.rating + (b.reviews / 100); return scoreB - scoreA;

Why This Works

  • Quality: High ratings get priority
  • Credibility: More reviews = more trustworthy
  • Balance: Prevents manipulation by fake ratings

📋 Overview

The Home Screen of SalonBooking.lk features two main service sorting mechanisms that help users discover the best services based on different criteria:

🔥 Popular Services

Services ranked by popularity score, showing the most frequently booked services by customers.

⭐ Top Rated Services

Services sorted by rating combined with review count, highlighting the highest quality services.

Key Features: Real-time sorting, responsive design, loading states, and fallback content when no services are available.

🔥 Popular Services

How it Works

Popular services are determined by a popularityScore field in the Service model. This score is calculated based on:

  • Booking Frequency: Number of bookings for the service
  • View Count: How many times the service has been viewed
  • Recent Activity: Last booking date affects the score
  • Service Status: Only ACTIVE services are considered

Sorting Algorithm

// Sort by popularity score (highest first) const popularServices = [...transformedServices] .sort((a, b) => b.popularityScore - a.popularityScore) .slice(0, 8); // Limit to top 8 services

Visual Presentation

Popular services are displayed in a responsive grid layout with:

  • Purple gradient heading ("Popular Services")
  • Descriptive subtitle: "Most booked services by our customers"
  • 4-column grid on desktop, responsive on mobile
  • ServiceCard components with hover effects
  • "View all" link to browse more services

⭐ Top Rated Services

Rating Algorithm

Top rated services use a sophisticated scoring system that combines average rating with review count:

// Combined score calculation const scoreA = a.rating + (a.reviews / 100); // Normalize reviews const scoreB = b.rating + (b.reviews / 100); // Sort by combined score (highest first) return scoreB - scoreA;

Why This Algorithm?

🎯 Quality Focus

Prioritizes services with high ratings (1-5 stars)

📊 Credibility

Considers review count to avoid services with fake high ratings

⚖️ Balance

Normalized review count prevents overwhelming by quantity alone

Rating System Components

  • averageRating: Calculated from all user ratings (0-5)
  • reviewCount: Total number of reviews received
  • Rating Model: Stores individual ratings with comments
  • Auto-calculation: Service ratings update when new reviews are added

Visual Presentation

Top rated services feature:

  • Blue gradient heading ("Top Rated Services")
  • Descriptive subtitle: "Highest rated services by our customers"
  • Same responsive grid layout as popular services
  • Star rating display in service cards
  • "View all" link with rating sort parameter

const [popularServices, setPopularServices] = useState<Service[]>([]); const [topRatedServices, setTopRatedServices] = useState<Service[]>([]); const [loading, setLoading] = useState(true); // Fetch services on component mount useEffect(() => { async function fetchServices() { try { const response = await fetch('/api/services/home'); const data = await response.json(); setPopularServices(data.popularServices || []); setTopRatedServices(data.topRatedServices || []); } catch (err) { // Error handling with fallback setPopularServices([]); setTopRatedServices([]); } finally { setLoading(false); } } fetchServices(); }, []);

🌐 API Endpoints

GET /api/services/home

Fetches popular and top-rated services for the home page

Response Format:

{ "popularServices": [ { "id": "service_id", "title": "Service Name", "image": "image_url", "price": 2500, "salon": "Salon Name", "salonContextId": "salon_id", "location": "Colombo", "rating": 4.5, "reviews": 23, "popularityScore": 15.7, "type": "HAIRCUT" } ], "topRatedServices": [ // Same structure, sorted by rating ] }
GET /api/services/search

Search services with sorting options (used by "View all" links)

Query Parameters:

  • sort - "popularity" or "rating"
  • limit - Number of results to return
  • search - Search query
POST /api/ratings

Submit new ratings for services (affects top-rated sorting)

Request Body:

{ "appointmentId": "appointment_id", "serviceId": "service_id", "salonId": "salon_id", "rating": 5, "comment": "Excellent service!" }

🗄️ Database Models

Service Model

Field Type Description Used in Sorting
popularityScore Number Calculated popularity metric ✅ Popular Services
averageRating Number (0-5) Average of all user ratings ✅ Top Rated Services
reviewCount Number Total number of reviews ✅ Top Rated Services
views Number Service view count ➡️ Affects popularity
bookings Number Number of bookings ➡️ Affects popularity
status Enum ACTIVE, INACTIVE, PENDING, REJECTED 🔍 Filter (ACTIVE only)

Rating Model

Field Type Description
userId ObjectId User who gave the rating
serviceId ObjectId Service being rated
rating Number (1-5) Star rating value
comment String Optional review comment
appointmentId ObjectId Related appointment
Important: The rating system automatically updates Service.averageRating and Service.reviewCount when new ratings are submitted.
