# SEO Images

To complete the SEO setup, please add the following images to your /public directory:

## Required Images:

1. **og-image.jpg** (1200x630px)
   - Open Graph image for social media sharing
   - Should showcase the SalonBooking.lk brand and services

2. **twitter-image.jpg** (1200x675px) 
   - Twitter card image
   - Can be same as og-image.jpg or Twitter-optimized version

3. **apple-touch-icon.png** (180x180px)
   - Apple device home screen icon
   - Should be the app logo/icon

4. **favicon.ico** (32x32px)
   - Browser favicon
   - Should be the brand icon

## Image Guidelines:
- Use high-quality images that represent the beauty/salon industry
- Include the SalonBooking.lk logo prominently
- Use brand colors (purple gradients based on the site design)
- Ensure text is readable when images are scaled down
- Consider showing diverse people enjoying salon services

## Tools for Creating Images:
- Canva (canva.com) - Great templates for social media
- Figma (figma.com) - Professional design tool
- Adobe Creative Suite - Professional tools
- Online favicon generators for favicon.ico

## Example Content Ideas:
- Beautiful salon interior with "Book Premium Salon Services" text
- Before/after transformation photos
- Happy customers with stylists
- Collection of beauty services (hair, nails, facial, etc.)
- Sri Lankan landmarks with beauty theme
